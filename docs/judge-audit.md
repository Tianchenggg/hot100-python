## 本次修复

| 范围 | 修复前的问题 | 现在的检查 |
| --- | --- | --- |
| 438 · 找到所有字母异位词 | 正确下标换个顺序会被判错 | 接受任意顺序，拒绝重复、遗漏和多余下标 |

| 返回类型 | JSON 会把 `3.0` 与 `3` 变成相同的 JavaScript 数值 | 序列化前按函数签名检查整数、布尔值、数组和节点值；类操作同样检查 |
| 浮点结果 | 数值很大时相对容差过宽；溢出数值可能通过 | 只接受有限数，中位数结果的绝对误差不超过 `1e-5` |

原有校验继续覆盖：无序答案的顺序与重复次数、空子集、最长回文与最小覆盖串的不同合法答案、N 皇后棋盘、平衡搜索树结构、高频元素边界、深拷贝与原链表保护、环入口与相交节点身份、原地修改参数、异常输出中的环和共享树节点。

ACM 使用题面中说明的文本输入输出格式。LeetCode 模式使用函数参数、返回值与节点对象。ACM 只能检验输出，无法从输出证明程序在内部交换了节点或没有修改数组。

## 可复现验证

```sh
npm ci
npm run check
npm test
```

`scripts/checker-test.mjs` 检查每个 ACM 测试答案及多种正确、错误输出；`scripts/leetcode-test.mjs` 检查每个 LeetCode 测试答案，并在真实 Pyodide 中执行节点、类型、原地修改和错误定位回归。`scripts/runner-test.mjs` 检查执行隔离、输出限制、超时与取消。

测试数量随题库增长，以命令实际输出为准。所有特殊规则都有针对正确替代答案和错误实现的回归用例。

## 边界

- 这是独立练习站，测试集不等同于 LeetCode 官方隐藏测试；通过本站用例不构成算法在所有输入上正确的证明。
- 超时限制能中断运行，但不能严格证明算法满足渐进时间或空间复杂度。进阶复杂度要求仍需要分析。
- 代码在访问者自己的浏览器里运行，适合练习，不提供竞赛场景下的服务端防作弊保证。
